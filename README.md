# 英雄传说：命之轨迹 TRPG — Foundry VTT 系统（非官方）

《The Legend of Heroes: Trails of Destiny》（Promethium System）的饭制自动化系统，目标版本 **Foundry VTT v12**（已按 12.343 的 API 编写）。

> 非官方项目。请勿把规则书原文、插图打包进本仓库或公开的合集包。
>
> 中文译名与规则以汉化版《英雄传说：命之轨迹TRPG V1.1》（CHM）为准。

## 当前功能（0.1.0）

| 模块 | 内容 |
| --- | --- |
| 角色卡 | 九项属性及其奖励骰（15 起 +1，每 5 点 +1；低于 5 记 1 个挑战）；21 项核心技能（可改用属性、填写技能奖励骰）；耐久、生命值、活力、魔力、导力能量上限自动计算（含每级成长与额外加成）；物防、魔防、护甲等级、行动次数、移动力自动计算；命定开关 |
| 敌手卡 | 按敌手数据块录入：对手等级、风险等级、战斗属性（攻击、侵袭、防御、抵抗……均为已含属性值的奖励骰）、资源、奖励 |
| 物品 | 武器、护甲、战技、结晶回路、天赋、道具；物品上的主动效果会转移给持有者（用于天赋加属性等） |
| 检定面板 | 参考 Lancer 的检定流程：点击检定后，在画面右下角（聊天栏左侧）弹出检定面板。加值／减值以复选框列出（技能、属性、负伤、属性过低、绽放命运……），冒险用 1–3 个圆点点选，额外奖励骰、蓄势、挑战、固定修正用加减按钮调整；最终公式、奖励骰骰型和骰阶条随每次调整即时刷新。伤害等效应检定使用同一面板（效应骰数量、力量奖励骰、冒险转化的蓄势） |
| 目标与掩护 | 面板下方列出当前选中的目标，与场景中的选中状态双向同步；每个目标可单独指定无掩护、轻度（物防 +10）、部分（物防 +3、护甲 +5）、完全（物防 +5、护甲 +10），并显示各自的 VS。命中结果逐目标写进聊天卡片，掩护的护甲加值会带到伤害卡片 |
| 检定 | 1d20 + N 颗奖励骰（d10 起，按蓄势和挑战升降一级，最低 d4，最高 d20）；奖励骰掷出最大值时爆发，无限连爆；每点冒险 +15 VS，并给效应掷骰 +1 蓄势；负伤自动下降一级 |
| 战斗 | 攻击与战技对每个目标分别比较物防或魔防；命中后显示「掷伤害」按钮，承担的冒险会转为伤害奖励骰的蓄势，命中的目标连同掩护带入伤害面板；伤害卡片上可逐目标选择倍率（×2 / ×1 / ×½）并应用，也可应用到选中的 Token；应用伤害先扣护甲等级（含掩护），再扣耐久，溢出部分转入生命值，并处理负伤、休克和死亡，聊天栏留下可撤销的伤害记录；反应检定需严格高于对方；防御反应消耗 5 活力，抵抗反应消耗 5 魔力；所有战技都进行行动检定并自动扣除消耗；活力耗尽时自动陷入气短 |
| 命定 | 行动检定掷出自然 20、任意一次掷骰（含伤害）爆发 3 颗奖励骰、承担 3 点冒险并命中，满足任一条件时自动进入命定状态；处于命定时，检定面板的加值栏会出现两个互斥的「绽放命运」选项（消耗命定，本回合不再进入命定）：「加骰」为这次行动或反应掷骰 +3 奖励骰；「突破传奇」只在可承担冒险的行动检定中出现，勾选后强制锁定 3 点冒险，之后的效应掷骰（伤害）奖励骰上限从 d20 提升到 d100，实际骰阶仍由蓄势与挑战决定 |
| 其他 | 先攻 = 1d20 + 先攻奖励骰；22 种状态异常；把物品拖到快捷栏会生成宏；中英文界面 |

尚未实现：导力器构筑（准备从 `../Orbment_web/js/rules.js` 移植）、导力魔法施放、战技范围模板、反应与攻击的自动对抗、玩家对不属于自己的 Token 应用伤害（目前需由 GM 点击）、治疗等非伤害的效应检定入口、武器与护甲的品质克制（无视低品质护甲、护甲免疫低品质伤害、卓越耐久）、休克倒计时、合集包内容。

## 接入 Foundry（Windows）

1. 在 foundryvtt.com 的 Purchased Licenses 页面，从版本下拉框选择 **Version 12**（12.343），下载并安装，首次启动时输入授权码。
2. 用目录联接把本仓库挂到 Foundry 的数据目录。**目录名必须是 `trails-of-destiny`**，与 `system.json` 里的 `id` 一致。在 PowerShell 中执行：

   ```powershell
   New-Item -ItemType Junction -Path "$env:LOCALAPPDATA\FoundryVTT\Data\systems\trails-of-destiny" -Target "D:\TRPG\Trials_cn\Trials_fvtt"
   ```

   如果你改过 Foundry 的数据路径，可以在启动界面的 Configuration 页查看「User Data Path」。
3. 重启 Foundry，Game Systems 列表中会出现「英雄传说：命之轨迹 TRPG（非官方）」。用它新建一个测试世界。
4. 在 Configure Settings → Language 中选择「中文（简体）」并重新加载，本系统的界面会变成中文。Foundry 核心界面需要另装简体中文翻译模块才会变成中文。

## 扩展检定流程

流程步骤登记在 `game.trails.flowSteps` 中，可以在世界脚本或模组里替换或插入步骤，例如：

```js
const { ActionFlow } = game.trails.flows;
game.trails.flowSteps.set("announceAttack", async state => {
  ui.notifications.info(`${state.actor.name} 发起了 ${state.data.title}`);
});
ActionFlow.insertStepBefore("showActionHUD", "announceAttack");
```

每个流程开始与结束时会触发 `trails.preFlow.<流程名>` 与 `trails.postFlow.<流程名>` 钩子。

## 开发循环

- **改规则逻辑**（`module/rules/`）：先写测试，然后运行 `npm test`，几秒钟出结果，不需要启动 Foundry。
- **改 CSS、模板、语言文件**：`system.json` 已开启 hotReload，保存后 Foundry 通常会自动刷新；通过目录联接挂载时偶尔不会触发，没反应就按 F5。
- **改其他 JS**：在浏览器中按 F5 重新加载世界。
- **排错**：按 F12 打开控制台，查看以 `trails-of-destiny |` 开头的日志和报错。可以在控制台直接调用 `game.trails.rules.dice.actionPool({bonusDice: 3})` 等规则函数。

```bash
npm install   # 只需一次，用于模板编译测试
npm test
```

## 手动验收清单

在测试世界中依次检查：

1. 新建角色，把属性改为耐力 15、决心 13、灵性 17 → 资源上限应为 耐久 28 / 生命 25 / 活力 35 / 魔力 33 / EP 220。
2. 点击技能名 → 右下角弹出检定面板。点冒险圆点、加减额外奖励骰／蓄势／挑战、取消勾选负伤，公式和骰阶应即时变化；填写 VS 后掷骰，聊天卡片应显示公式、总值（点击展开骰子明细）、成功／失败和爆发次数。
3. 新建武器（伤害值 2、普通品质、勾选加力量）→ 选中一个或多个目标 → 点 d20 图标攻击。面板下方应列出目标及其物防；为某个目标选「部分掩护」，其 VS 应 +3；在场景中取消选中目标，面板应同步移除。
4. 命中后点「掷伤害」→ 伤害面板应带入命中的目标和掩护（护甲 +5），「冒险转化」显示为蓄势 → 掷骰 → 在伤害卡片的目标行选倍率并点红色按钮，检查耐久和生命值的扣减、负伤状态图标；再点伤害记录上的撤销按钮，数值应恢复。
5. 防御反应应扣 5 活力，抵抗反应应扣 5 魔力，资源不足时会给出提示；反应面板中不能承担冒险，平局判为失败。
6. 角色处于命定时，面板的加值栏会出现「绽放命运：加骰」和「绽放命运：突破传奇」，两者只能选一个。选「加骰」后奖励骰 +3；选「突破传奇」后冒险被锁定为 3 点（VS +45）。掷骰后命定状态被消耗。命中后点「掷伤害」，伤害面板的骰阶条应延伸到 d100：3 点蓄势且无挑战时奖励骰为 d100，有负伤时只到 d20。
7. 在天赋上添加主动效果「system.abilities.str.value / 加 / 2」并拖给角色 → 力量 +2，奖励骰随之变化。
8. 战斗追踪器中掷先攻；角色负伤时，先攻的奖励骰应下降一级。

## 规则存疑处

- V1.1 属性值奖励骰表中「1-5 挑战 / 5-14 无」区间仍然重叠；参照敌手数据块（属性值 5 记 +0），按「低于 5 记挑战」处理。
- 第 3 章「攻击与防御」一节先说攻击需「达到或超过」物防，后又说需「高于」物防；本系统按通用规则「达到或超过 VS 即成功」处理。
- 「行动检定掷出自然 20」进入命定：本系统对反应检定（防御、抵抗）的自然 20 也同样判定。
- 核心技能的默认属性由本系统指定，规则书原文是由 GM 按情境决定，在角色卡上可以逐项修改。
- 远程武器不会自动加力量奖励骰；新建远程武器时请取消勾选「伤害加上力量奖励骰」。
- 掩护的适用范围（轻度掩护只对直接远程攻击、完全掩护的护甲加值只对远程攻击）由玩家在面板中自行判断，系统不区分近战／远程／区域。掩护只加物防，不加魔防。
- 多目标攻击时，命中任一目标即视为「成功」，用于「承担 3 点冒险并成功」的命定判定。
- 绽放命运「通过承担冒险，可以将行动检定的结果蓄势至传奇级之上」：未找到官方答疑。本系统的做法是在行动检定时宣告并消耗命定、锁定 3 点冒险，只放宽之后那次效应掷骰的奖励骰上限（d100）；能否真正到达 d100 仍取决于蓄势与挑战的净值。行动检定本身的奖励骰上限不变。
