# 规则取舍

规则书（中文译本 V1.1）中表述不明确或有冲突的地方，本系统的处理方式如下。GM 可以按自己的理解手动调整结果。

## 检定与属性

- 属性值奖励骰表中「1-5 挑战 / 5-14 无」区间重叠：参照敌手数据块（属性值 5 记 +0），按「低于 5 记挑战」处理。
- 核心技能的默认属性由本系统指定；规则书原文由 GM 按情境决定，可在角色卡上逐项修改。
- 「行动检定掷出自然 20」进入命定：反应检定（防御、抵抗）的自然 20 也同样判定。

## 攻击、掩护与伤害

- 第 3 章「攻击与防御」先说攻击需「达到或超过」物防，后又说需「高于」物防：按通用规则「达到或超过 VS 即成功」处理。反应检定仍需严格高于对方。
- 远程武器不会自动加力量奖励骰；新建远程武器时请取消勾选「伤害加上力量奖励骰」。
- 掩护的适用范围（轻度掩护只对直接远程攻击、完全掩护的护甲加值只对远程攻击）由玩家在面板中自行判断，系统不区分近战、远程与区域。掩护只加物防，不加魔防。
- 多目标攻击时，命中任一目标即视为「成功」，用于「承担 3 点冒险并成功」的命定判定。

## 命定

- 绽放命运「通过承担冒险，可以将行动检定的结果蓄势至传奇级之上」：未找到官方答疑。本系统的做法是在行动检定时宣告并消耗命定、锁定 3 点冒险，只放宽之后那次效应掷骰的奖励骰上限（d100）；能否真正到达 d100 仍取决于蓄势与挑战的净值。行动检定本身的奖励骰上限不变。

## Token 资源条

- Bar Brawl 会把它处理过的 Token 的核心显示模式固定为「始终」。之后若停用 Bar Brawl，NPC 的资源条需要手动改回「拥有者可见」。
